OneOCR semantic XHTML — legacy asset host

This repository is frozen. Development moved to github.com/oneocr on 18 August 2026.

The files here keep working, permanently. Every OCR document generated before the move links its stylesheet and script from this path:

  • https://xyz-jphil.github.io/win11_oneocr_semantic_xhtml/styles.css
  • https://xyz-jphil.github.io/win11_oneocr_semantic_xhtml/scripts.js

Those two URLs are deliberately left in place and served from this repository, so that already-generated documents continue to render exactly as they always did. They are not redirected — a redirect cannot carry a stylesheet.

Why this repository was not simply moved

Transferring a repository between GitHub organisations changes its Pages host, and GitHub Pages does not redirect across a transfer. Moving this one would have stripped the stylesheet and all interactivity from every document already produced and archived. Keeping it in place costs nothing and breaks nothing.
